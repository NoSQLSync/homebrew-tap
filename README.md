# NoSQLSync Homebrew tap

```sh
brew install nosqlsync/tap/nosqlsync
```

[nosqlsync](https://github.com/NoSQLSync/nosqlsync) migrates MongoDB to
PostgreSQL with a schema you'd actually design: analyze, plan, migrate with
COPY, validate.

`Formula/nosqlsync.rb` is generated by the
[release workflow](https://github.com/NoSQLSync/nosqlsync/blob/main/.github/workflows/homebrew.yml)
each time nosqlsync is released. Changes made here by hand are overwritten.
